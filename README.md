# Felices 5 mesesitos

Página romántica estática hecha con HTML, CSS y JavaScript, lista para publicar
con GitHub Pages.

## Archivos

- `index.html`: página y estilos.
- `Trippie Redd Performs Wish With Live Orchestra Audiomack Trap Symphony.mp3`:
  música que comienza al abrir la cartita.

Mantén el HTML y el MP3 en la raíz del repositorio para que el enlace de audio
siga funcionando.

## Vista previa local

Desde esta carpeta, ejecuta:

```powershell
python -m http.server 8000
```

Luego abre `http://localhost:8000`.

## Publicar con GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html`, este `README.md`, `.gitignore` y el MP3 a la raíz del
   repositorio. También puedes usar **Add file > Upload files** en GitHub.
3. En GitHub, abre **Settings > Pages** y elige desplegar desde la rama
   `main`, carpeta `/ (root)`.

GitHub publicará el sitio en la URL que indique la sección Pages del repositorio.
